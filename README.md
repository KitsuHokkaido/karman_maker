# TPs Maillage SALOME
---

## Présentation 
---

Au cours de ces tps vous allez apprendre à utiliser l'API Python de Salome. 
L'objectif est de vous rendre indépendant sur cet API, notamment en vous apprenant 
à vous repérer dans la documentation.

Ce TP se déroulera en 3 sous séances : 

1. Présentation de la syntaxe de base de l'API, construction d'une géométrie 
simple, des groupes (conditions limites) et du maillage.
2. Construction en autonomie du maillage lié au cas test de Von Karman.
3. Optimisation topologique automatique du maillage.
